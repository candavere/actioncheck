# Corpus
19 composite actions from popular repos, pinned to the commit in manifest.json (fetched 2026-11-25 by fetch.py).
Each file belongs to its upstream repo and is under that repo's license. They are kept here only as test data, and are not in the npm package.
- findings.txt: actioncheck output on the corpus, reviewed by hand (see RUNLOG.md)
- mutate.mjs / mutation-results.txt: one bug injected per rule per file, and the detection counts
